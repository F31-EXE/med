# CLAUDE.md

## Что это за проект

Статичные визуальные макеты лендинга для компании-организатора медицинских мероприятий (конгрессы, научные конференции, обучающие семинары, выставки медтехники, онлайн-симпозиумы). Это не рабочий сайт: макеты делают только для скриншотов, чтобы показать заказчику разные варианты дизайна.

## Структура

```
01-clinical-trust/index.html    — МедФорум: белый/голубой/синий, Inter, строгий медицинский стиль
02-modern-tech/index.html       — MEDX.events: тёмно-синий + бирюзово-фиолетовые градиенты, Unbounded + Manrope, шестиугольники
03-corporate-premium/index.html — Medicus Congress Group: тёмно-синий/графит + золото, Cormorant Garamond + Montserrat
04-soft-care/index.html         — Вместе Мед: пастель (мята, голубой, персик), Nunito, скругления, SVG-иллюстрации людей
```

Каждая папка содержит один самодостаточный `index.html` со всем CSS внутри тега `<style>`. Сборки, зависимостей и JS нет.

## Обязательные блоки (в этом порядке на каждой странице)

1. Header (логотип + меню)
2. Hero (заголовок, подзаголовок, кнопка)
3. Цифры (лет опыта, мероприятий, участников, врачей-спикеров)
4. Виды мероприятий: 5 карточек (конгрессы, научные конференции, семинары, выставки медоборудования, онлайн-симпозиумы)
5. Галерея / портфолио
6. Этапы работы: заявка → программа → логистика → проведение
7. Отзывы (2–3)
8. Партнёры (логотипы-заглушки)
9. Контакты / CTA
10. Footer

## Правила

- Только HTML + CSS. JS не добавлять (разве что минимум для красоты).
- Ширина вёрстки ~1440px (`<meta name="viewport" content="width=1440">`), контейнер `.wrap` 1200–1240px. Адаптивность не нужна.
- Весь текст на русском. Компании, имена, цифры и контакты вымышленные.
- Фото берутся с Unsplash (`images.unsplash.com/photo-...?w=...&q=80`) через `background-image` на элементах с классом `.ph`. У `.ph` есть градиентная подложка, поэтому незагрузившееся фото не ломает вид страницы. Сохраняйте этот приём.
- Шрифты подключаются через Google Fonts и должны поддерживать кириллицу.
- Цвета каждого стиля заданы CSS-переменными в `:root`. Меняйте палитру через них.
- Стили четырёх вариантов должны заметно отличаться друг от друга. Не унифицируйте их.
- Комментарии в коде не нужны.

## Проверка

Скриншот всей страницы в headless Chromium (в облачной среде):

```
/opt/pw-browsers/chromium-*/chrome-linux/chrome --headless --no-sandbox --hide-scrollbars \
  --window-size=1440,7000 --screenshot=out.png file://$PWD/01-clinical-trust/index.html
```

Из облачного контейнера Unsplash и Google Fonts недоступны, поэтому на скриншотах будут подложки и системные шрифты. Проверять так можно только сетку. Окончательно внешний вид смотрите в обычном браузере.
